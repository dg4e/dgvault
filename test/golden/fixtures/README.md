# Golden KDBX fixtures

These reference databases are generated by **KeePassXC** (independent of dgvault's
own reader/writer) so the golden round-trip tests validate true KeePass interop,
not our own implementation against itself.

Do not hand-edit the `.kdbx` files. Regenerate with the commands below and commit
both the `.kdbx` and its `*.expected.json` sidecar.

## Prerequisites
- `keepassxc-cli` (KeePassXC ≥ 2.7)

## Generation (Phase 1 — run when the core writer/reader is being tested)

```bash
# AES-256 + Argon2id
keepassxc-cli db-create --set-password \
  --set-key-algorithm argon2 aes-argon2.kdbx   # password: correcthorsebatterystaple

# ChaCha20 + Argon2id
keepassxc-cli db-create --set-password \
  --set-key-algorithm argon2 chacha-argon2.kdbx

# Composite key (password + key file)
keepassxc-cli db-create --set-password --set-key-file keyfile.key keyfile.kdbx

# Then populate entries/groups/attachments via `keepassxc-cli add` / `import`,
# and export the logical contents to the *.expected.json sidecar (see
# scripts/gen_expected.dart, added in Phase 1).
```

## Sidecar format (`*.expected.json`)
```json
{
  "credentials": { "password": "correcthorsebatterystaple", "keyfile": null },
  "cipher": "aes256-cbc",
  "kdf": "argon2id",
  "groups": [{ "name": "Root", "entries": [ /* ... */ ] }],
  "entryCount": 0,
  "attachmentHashes": {}
}
```
